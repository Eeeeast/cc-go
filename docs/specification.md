# Спецификация языка MiniGo

## Введение

MiniGo — минималистичный язык с синтаксисом, похожим на Go. Он предназначен для обучения разработке интерпретаторов в рамках курса по теории формальных языков программирования

### Особенности

1. Программа содержит 1 входной файл с исходным кодом. Точка входа — функция `main`
2. Основной стиль программирования — процедурный программа является набором функций
3. Базовые типы:
   - `int` — 64-битное целое число со знаком
   - `string` — строка
   - `bool` — булево значение
4. Есть ветвление `if`/`else` и цикл `for`, из которого можно выйти с помощью `break` и `continue`.
5. Массивы - срезы, создаваемые функцией `make`, длина массива определяется функцией `len` 
6. Есть структуры `struct`
7. Ввод и вывод выполняются встроенными функциями `fmt.Println`

## Лексика

### Пробельные символы

Пробельные символы разделяют лексемы

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

### Комментарии

1. Строчный комментарий начинается с `//` и идет до конца строки
2. Блок комментария(многострочный) начинается с `/*` и заканчивается `*/`
3. Комментарии игнорируются при разборе

### Идентификаторы

1. Идентификатор - последовательность букв, цифр и знака "_"
2. Регистр при написание имеет значение `count` и `Count` - разные идентификаторы
3. Идентификатор не может совпадать с ключевым или зарезервированным словом.

### Ключевые слова

```
break   continue  for    if    else
func    struct    int    bool  string
return  true      false  type  var
```

### Литералы целых чисел

1. Литерал — последовательность цифр
2. Литерал не содержит знака, отрицательное число это оператор `-` и литерал цифры
3. Дробные литералы не поддерживаются

### Литералы строк

Литерал заключён в двойные кавычки: "строка". Внутри возможны любые символы, кроме ", \ и EOL - эти символы записываются через \:

| Запись | Символ               |
| ------ | -------------------- |
| \"     | двойная кавычка      |
| \\     | обратная косая черта |
| \n     | перевод строки       |
| \t     | табуляция            |

Любая другая последовательность после \ является ошибкой

### Операторы

| Группа         | Лексемы                     |
| -------------- | --------------------------- |
| Арифметические | `+` `-` `*` `/` `%`         |
| Сравнения      | `==` `!=` `<` `<=` `>` `>=` |
| Логические     | `&&` `\|\|` `!`             |
| Присваивание   | `=` `:=`                    |

### Разделители

`(` `)` `[` `]` `{` `}` `,` `;` `.`

### Разделители инструкций

Токен `;` используется для разделения инструкций:

1. Токен `;` требуется в конце строки после последней лексемы строки, если она:
   - идентификатор
   - литерал целого числа или строки
   - одно из ключевых слов break continue int bool string return true false
   - одна из закрывающих скобок разделителей
2. Строки состоящие только из комментариев токен `;` не требуют

### Лексические ошибки

1. символ, с которого не может начинаться ни одна лексема
2. одиночные `&`, `|` и `:`
3. литералы нарушающие правила написания
4. не закрытые блочные коментарии
