# Спецификация языка MiniGo

## Введение

> Данный документ описывает только правила, которые будут реализованы на текущем этапе.

MiniGo — минималистичный язык с синтаксисом, похожим на Go. Он предназначен для обучения разработке интерпретаторов в рамках курса по теории формальных языков программирования.

### Особенности

1. Программа состоит из одного файла с исходным кодом. Точка входа — функция `main`.
2. Основной стиль программирования — процедурный.
3. Единственный тип данных — `int` (64-битное целое число со знаком).
4. Переменные не поддерживаются.
5. Ввод и вывод выполняются встроенными функциями `fmt.Println` и `fmt.ReadInt`.

### В следующих итерациях нужно добавить:

1. Типы данных:
   - `string` — строка;
   - `bool` — булево значение;
   - срезы, создаваемые функцией `make`, с определением длины через `len`;
   - структуры `struct`.
2. Объявление переменных с помощью `var` или `:=`.
3. Ветвление `if`/`else` и цикл `for` с операторами `break` и `continue`.
4. Пользовательские функции.

### Связь с другими языками:

1. Синтаксис функции `main`, сигнатур встроенных функций (`abs(x int) int`) и префикс `fmt.` у функций ввода-вывода заимствованы из Go.
2. В отличие от Go, автоматическая вставка `;` отсутствует — каждая инструкция явно завершается точкой с запятой, как в C.

## Лексика

Раздел описывает все лексемы языка, включая те, что будут использоваться в следующих итерациях.

### Пробельные символы

Пробельные символы разделяют токены и игнорируются при разборе.

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

### Комментарии

1. Строчный комментарий начинается с `//` и идёт до конца строки.
2. Блочный комментарий (многострочный) начинается с `/*` и заканчивается первым `*/`.
3. Комментарии приравниваются к пробельным символам.

### Идентификаторы

1. Идентификатор (`identifier`) — последовательность латинских букв, цифр и знака `_`, которая начинается с латинской буквы или знака `_`.
2. Регистр имеет значение: `count` и `Count` — разные идентификаторы.
3. Идентификатор не может совпадать с ключевым словом.

### Ключевые слова

```
break continue for if else func struct return true false type var
```

Ключевые слова пишутся только строчными буквами. `IF` и `If` — обычные идентификаторы. Имена встроенных функций (`abs`, `min`, `max`, `make`, `len`, `fmt`, `Println`, `ReadInt`) и имя точки входа `main` — также обычные идентификаторы.

### Литералы целых чисел

1. Литерал (`integer_literal`) — последовательность десятичных цифр.
2. Литерал не содержит знака: отрицательное число — это оператор `-` и литерал.
3. Дробные литералы не поддерживаются.
4. Не допускаются литералы целых чисел, значение которых превышает `9223372036854775807`.
5. Литерал завершается на первом символе, не являющемся цифрой. Если за цифрами без разделителя следуют буквы или знак `_` (например, `123abc`), вход разбирается как два отдельных токена: целочисленный литерал (`123`) и идентификатор (`abc`).

### Литералы строк

Литерал заключён в двойные кавычки: `"строка"`. Внутри возможны любые символы, кроме `"`, `\`, переноса строки и возврата каретки. Символы `"` и `\` и управляющие символы переноса/табуляции записываются через `\`:

| Запись | Символ               |
| ------ | -------------------- |
| `\"`   | двойная кавычка      |
| `\\`   | обратная косая черта |
| `\n`   | перенос строки       |
| `\r`   | возврат каретки      |
| `\t`   | табуляция            |

Неэкранированный перенос строки внутри литерала или возврат каретки, незакрытый литерал и любая другая последовательность после `\` — лексические ошибки.

### Операторы

Из нескольких подходящих лексем выбирается самая длинная: `<=` — это один оператор, а не `<` и `=`.

| Группа         | Токены                      |
| -------------- | --------------------------- |
| Арифметические | `+` `-` `*` `/` `%`         |
| Сравнения      | `==` `!=` `<` `<=` `>` `>=` |
| Логические     | `&&` `\|\|` `!`             |
| Присваивание   | `=` `:=`                    |

### Разделители

`(` `)` `[` `]` `{` `}` `,` `;` `.`

### Разделители инструкций

Лексер не вставляет `;` автоматически: токен присутствует в потоке только там, где он явно написан в исходном коде.

### Лексические ошибки

1. Символ, с которого не может начинаться ни один токен.
2. Одиночные `&`, `|` и `:`.
3. Литералы, нарушающие правила написания, включая переполнение целочисленного литерала.
4. Незакрытый блочный комментарий.

## Синтаксис

```ebnf
(* Программа состоит из функции main *)
program = "func" , identifier , "(" , ")" , "{" , { statement } , "}" , ? конец файла ? ;

(* Инструкция — выражение, завершённое точкой с запятой *)
statement = expression , ";" ;

(* Выражение *)
expression = additive_expression ;

(* Сложение и вычитание *)
additive_expression = multiplicative_expression , { ( "+" | "-" ) , multiplicative_expression } ;

(* Умножение, деление и остаток от деления *)
multiplicative_expression = unary_expression , { ( "*" | "/" | "%" ) , unary_expression } ;

(* Унарный минус *)
unary_expression = "-" , unary_expression | primary_expression ;

(* Элементарное выражение: литерал, вызов функции или выражение в скобках *)
primary_expression = integer_literal
                   | call_expression
                   | "(" , expression , ")" ;

(* Вызов встроенной функции, в том числе с префиксом пакета, например fmt.Println *)
call_expression = identifier , [ "." , identifier ] , "(" , [ argument_list ] , ")" ;

(* Аргументы вызова функции *)
argument_list = expression , { "," , expression } ;
```

### Приоритет и ассоциативность операторов

Операторы выражений, от высшего приоритета к низшему:

| Приоритет | Операторы       | Описание                               | Ассоциативность |
| --------- | --------------- | -------------------------------------- | --------------- |
| 1         | `f(...)`, `( )` | Вызов функции, группировка             | —               |
| 2         | `-` (унарный)   | Смена знака                            | Правая          |
| 3         | `*`, `/`, `%`   | Умножение, деление, остаток от деления | Левая           |
| 4         | `+`, `-`        | Сложение, вычитание                    | Левая           |

## Семантика выражений

1. Инструкции выполняются по порядку, начиная с первой инструкции в теле функции `main`.
2. Значение выражения-инструкции отбрасывается.
3. Операнды и аргументы вычисляются слева направо.
4. Все вычисления выполняются над 64-битными целыми числами со знаком.
5. Деление `/` округляет результат к нулю: `7 / 2` равно `3`, `-7 / 2` равно `-3`.
6. Знак остатка `%` совпадает со знаком делимого: `-7 % 2` равно `-1`.

К ошибке выполнения приводят:

1. Деление или взятие остатка от деления на ноль.
2. Переполнение: результат операции не помещается в 64-битное целое со знаком.
3. Вызов неизвестной функции или вызов функции с неверным числом аргументов, например, передача не двух аргументов в `min` или `max`.
4. Использование результата функции, которая не возвращает значения, например, `1 + fmt.Println(2)`.
5. Ошибка ввода: ввод закончился или строка не является целым числом.

## Встроенные функции

| Функция                 | Описание                                                                                                              |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `fmt.Println(x)`        | Выводит значение (`int`, `bool` или `string`; на текущем этапе — `int`) с переносом строки LF, не возвращает значения |
| `fmt.ReadInt() int`     | Читает строку из ввода и возвращает записанное в ней целое число со знаком                                            |
| `abs(x int) int`        | Возвращает модуль числа                                                                                               |
| `min(a int, b int) int` | Возвращает меньшее из двух чисел                                                                                      |
| `max(a int, b int) int` | Возвращает большее из двух чисел                                                                                      |

Строка, прочитанная `fmt.ReadInt`, может содержать пробельные символы в начале и в конце.

## Выполнение программы

1. Интерпретатор принимает путь к файлу с исходным кодом первым аргументом командной строки.
2. Ввод программы читается из стандартного потока ввода, вывод записывается в стандартный поток вывода.
3. При лексической, синтаксической ошибке или ошибке выполнения интерпретатор прекращает работу, выводит сообщение об ошибке в стандартный поток ошибок и завершается с ненулевым кодом возврата.
4. Программа выполняется только после успешного разбора всего файла: при лексической или синтаксической ошибке инструкции не выполняются, а при ошибке выполнения вывод предшествующих инструкций сохраняется.
