# Спецификация языка MiniGo

## Введение

> Данный документ описывает только правила, которые будут реализованы на текущем этапе. Синтаксис и семантика описывают только текущую итерацию, а Лексика включает токены будущих этапов.

MiniGo — минималистичный язык с синтаксисом, похожим на Go. Он предназначен для обучения разработке интерпретаторов в рамках курса по теории формальных языков программирования.

### Особенности

1. Программа состоит из одного файла с исходным кодом. Точка входа — функция `main`.
2. Основной стиль программирования — процедурный.
3. Единственный тип данных — `int` (64-битное целое число со знаком).
4. Поддерживаются глобальные и локальные переменные, вложенные блоки `{ ... }` и пользовательские функции.
5. Ввод и вывод выполняются встроенными функциями `fmt.Println` и `fmt.ReadInt`.

### В следующих итерациях нужно добавить:

1. Типы данных:
   - `string` — строка;
   - `bool` — булево значение;
   - срезы, создаваемые функцией `make`, с определением длины через `len`;
   - структуры `struct`.
2. Объявление переменных с помощью `:=`.
3. Ветвление `if`/`else` и цикл `for` с операторами `break` и `continue`.

### Связь с другими языками:

1. Синтаксис объявления функций `func`, переменных `var`, сигнатур встроенных функций `abs(x int) int`, вариативных `min`/`max` и префикс `fmt.` у функций ввода-вывода заимствованы из Go.
2. Как и в Go, неинициализированные переменные получают нулевое значение `0`, а присваивание является инструкцией, а не выражением.
3. В отличие от Go, автоматическая вставка `;` отсутствует — каждая инструкция явно завершается точкой с запятой, как в C.

## Лексика

Раздел описывает все лексемы языка, включая те, что будут использоваться в следующих итерациях.

### Пробельные символы

Пробельные символы разделяют токены и игнорируются при разборе.

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

### Комментарии

1. Строчный комментарий начинается с `//` и идёт до конца строки.
2. Блочный комментарий (многострочный) начинается с `/*` и заканчивается первым `*/`.
3. Комментарии приравниваются к пробельным символам.

### Идентификаторы

1. Идентификатор (`identifier`) — последовательность латинских букв, цифр и знака `_`, которая начинается с латинской буквы или знака `_`.
2. Регистр имеет значение: `count` и `Count` — разные идентификаторы.
3. Идентификатор не может совпадать с ключевым словом.

### Ключевые слова

```
break continue for if else func struct return true false type var
```

Ключевые слова пишутся только строчными буквами. `IF` и `If` — обычные идентификаторы. Имена встроенных функций (`abs`, `min`, `max`, `make`, `len`, `fmt`, `Println`, `ReadInt`) и имя точки входа `main` — также обычные идентификаторы.

### Литералы целых чисел

1. Литерал `integer_literal` — последовательность десятичных цифр.
2. Литерал не содержит знака: отрицательное число — это оператор `-` и литерал.
3. Дробные литералы не поддерживаются.
4. Литерал завершается на первом символе, не являющемся цифрой. Если за цифрами без разделителя следуют буквы или знак `_` (например, `123abc`), вход разбирается как два отдельных токена: целочисленный литерал (`123`) и идентификатор (`abc`).

### Литералы строк

Литерал заключён в двойные кавычки: `"строка"`. Внутри возможны любые символы, кроме `"`, `\`, переноса строки и возврата каретки. Символы `"` и `\` и управляющие символы переноса/табуляции записываются через `\`:

| Запись | Символ               |
| ------ | -------------------- |
| `\"`   | двойная кавычка      |
| `\\`   | обратная косая черта |
| `\n`   | перенос строки       |
| `\r`   | возврат каретки      |
| `\t`   | табуляция            |

Неэкранированный перенос строки внутри литерала или возврат каретки, незакрытый литерал и любая другая последовательность после `\` — лексические ошибки.

### Операторы

Из нескольких подходящих лексем выбирается самая длинная: `<=` — это один оператор, а не `<` и `=`.

| Группа         | Токены                      |
| -------------- | --------------------------- |
| Арифметические | `+` `-` `*` `/` `%`         |
| Сравнения      | `==` `!=` `<` `<=` `>` `>=` |
| Логические     | `&&` `\|\|` `!`             |
| Присваивание   | `=` `:=`                    |

### Разделители

`(` `)` `[` `]` `{` `}` `,` `;` `.`

### Разделители инструкций

Лексер не вставляет `;` автоматически: токен присутствует в потоке только там, где он явно написан в исходном коде.

### Лексические ошибки

1. Символ, с которого не может начинаться ни один токен.
2. Одиночные `&`, `|` и `:`.
3. Литералы, нарушающие правила написания.
4. Незакрытый блочный комментарий.

## Синтаксис

Программа состоит из объявлений верхнего уровня: глобальных переменных и пользовательских функций. Точка входа — единственная функция `func main()` без параметров и возвращаемого значения.

```ebnf
(* Программа — последовательность объявлений верхнего уровня *)
program = { top_level_decl } , ? конец файла ? ;

top_level_decl = global_var_decl
               | func_decl ;

(* Объявление глобальной переменной; инициализатор опционален *)
global_var_decl = "var" , identifier , type , [ "=" , global_initializer ] , ";" ;

global_initializer = global_additive_expr ;
global_additive_expr = global_multiplicative_expr , { ( "+" | "-" ) , global_multiplicative_expr } ;
global_multiplicative_expr = global_unary_expr , { ( "*" | "/" | "%" ) , global_unary_expr } ;
global_unary_expr = "-" , global_unary_expr | global_primary_expr ;
global_primary_expr = integer_literal
                    | "(" , global_initializer , ")" ;

(* Объявление функции; возвращаемый тип опционален *)
func_decl = "func" , identifier , "(" , [ param_list ] , ")" , [ type ] , block ;
param_list = param , { "," , param } ;
param = identifier , type ;

(* Тип данных *)
type = "int" ;

(* Блок инструкций *)
block = "{" , { statement } , "}" ;

(* Инструкции *)
statement = local_var_decl
          | return_stmt
          | block
          | assignment_stmt
          | expression_stmt ;

local_var_decl = "var" , identifier , type , [ "=" , expression ] , ";" ;
return_stmt = "return" , [ expression ] , ";" ;
assignment_stmt = identifier , "=" , expression , ";" ;
expression_stmt = expression , ";" ;

(* Выражения *)
expression = additive_expression ;

(* Сложение и вычитание *)
additive_expression = multiplicative_expression , { ( "+" | "-" ) , multiplicative_expression } ;

(* Умножение, деление и остаток от деления *)
multiplicative_expression = unary_expression , { ( "*" | "/" | "%" ) , unary_expression } ;

(* Унарный минус *)
unary_expression = "-" , unary_expression | primary_expression ;

(* Элементарное выражение: литерал, переменная, вызов функции или скобки *)
primary_expression = integer_literal
                   | identifier , [ [ "." , identifier ] , "(" , [ argument_list ] , ")" ]
                   | "(" , expression , ")" ;

(* Аргументы вызова функции *)
argument_list = expression , { "," , expression } ;
```

### Синтаксические ограничения

1. Значение целочисленного литерала `integer_literal` не должно превышать `9223372036854775807`. Превышение этого значения является синтаксической ошибкой.

### Приоритет и ассоциативность операторов

Операторы выражений, от высшего приоритета к низшему:

| Приоритет | Операторы       | Описание                               | Ассоциативность |
| --------- | --------------- | -------------------------------------- | --------------- |
| 1         | `f(...)`, `( )` | Вызов функции, группировка             | —               |
| 2         | `-` (унарный)   | Смена знака                            | Правая          |
| 3         | `*`, `/`, `%`   | Умножение, деление, остаток от деления | Левая           |
| 4         | `+`, `-`        | Сложение, вычитание                    | Левая           |

## Семантика

### Переменные и области видимости

1. Тип и инициализация: все переменные и параметры имеют тип `int`. Переменная, объявленная без инициализатора `var x int;`, получает нулевое значение `0`.
2. Глобальные переменные: видны во всех функциях. Их инициализаторы вычисляются до запуска `main` в порядке объявления в файле.
3. Локальные переменные: видны с момента объявления и до конца блока, в котором объявлены. При вычислении инициализатора имя объявляемой переменной ещё не добавлено в текущую область видимости: в `var x int = x + 1;` идентификатор `x` справа ссылается на переменную из внешней области.
4. Присваивание: вычисляет выражение справа и записывает результат в ближайшую видимую переменную с указанным именем.
5. Единое пространство имён: глобальные переменные и пользовательские функции находятся в одном пространстве имён — объявление глобальной переменной и функции с одинаковым именем запрещено.
6. Затенение:
   - Повторное объявление имени в пределах одного блока запрещено.
   - Вложенный блок `{ ... }` создаёт новую область видимости и может затенять переменные из внешних блоков и глобальные переменные. Изменение затеняющей переменной не влияет на внешнюю.
   - Параметры функции и её внешний блок тела образуют одну область видимости: локальная переменная в корне тела функции не может совпадать по имени с параметром, но затенение параметра во вложенном блоке разрешено.
   - Имена `main`, `int`, `fmt`, `abs`, `min`, `max` зарезервированы под точку входа, тип и встроенные сущности: их нельзя использовать в качестве имён пользовательских функций, переменных и параметров.
7. Лексическая область видимости: функция видит глобальные переменные, свои параметры и локальные переменные, но не имеет доступа к локальным переменным вызывающей функции.

### Функции и вызовы

1. Точка входа: в программе должна быть ровно одна функция `func main()` без параметров и без возвращаемого значения. Явный вызов `main()` запрещён.
2. Видимость и уникальность: пользовательские функции видны во всём файле — функцию можно вызвать до её определения в коде (поддерживается рекурсия и взаимная рекурсия). Имена всех пользовательских функций должны быть уникальны.
3. Передача параметров: параметры передаются по значению — изменение параметра внутри функции не влияет на переменную вызывающей стороны.
4. Правила `return`:
   - В функции с возвращаемым типом `int` допускается только `return expression;`, и функция обязана гарантированно возвращать значение.
   - В функции без возвращаемого типа допускается только пустой `return;`. При достижении конца тела происходит неявный возврат.
   - Инструкция `return` внутри вложенного блока немедленно завершает всю текущую функцию.
5. Функции без возвращаемого значения: вызов такой функции разрешён только как самостоятельная инструкция `expression_stmt`. Его нельзя использовать внутри выражений, инициализаторов переменных, `return expression;` или в качестве аргумента другой функции.

### Вычисление выражений и ошибки

1. Инструкции выполняются последовательно. Значение выражения-инструкции типа `int` отбрасывается.
2. Операнды выражений и аргументы вызовов функций вычисляются строго **слева направо**.
3. Все вычисления выполняются над 64-битными целыми числами со знаком.
4. Деление `/` округляет результат к нулю: `7 / 2` равно `3`, `-7 / 2` равно `-3`.
5. Знак остатка `%` совпадает со знаком делимого: `-7 % 2` равно `-1`.

Семантические ошибки:

1. Отсутствие `func main()`, наличие нескольких `main` или неверная сигнатура `main`.
2. Обращение к необъявленной переменной или вызов неизвестной функции.
3. Повторное объявление переменной в одной области видимости, дублирование имён функций, конфликт имён функций и глобальных переменных, использование зарезервированных встроенных имён.
4. Вызов функции с неверным числом аргументов (включая вызов `min`/`max` без аргументов).
5. Использование результата функции, не возвращающей значения, внутри выражения.
6. Некорректный `return` (возврат значения из функции без типа возврата, пустой `return;` в `int`-функции) или отсутствие гарантированного `return` в `int`-функции.
7. Явный вызов `main()`.

К ошибке выполнения приводят:

1. Деление или взятие остатка от деления на ноль.
2. Переполнение: результат операции не помещается в 64-битное целое со знаком.
3. Ошибка ввода: ввод закончился или строка не является целым числом.

## Встроенные функции

| Функция                  | Описание                                                                     |
| ------------------------ | ---------------------------------------------------------------------------- |
| `fmt.Println(x)`         | Выводит значение `int` с переносом строки LF, не возвращает значения         |
| `fmt.ReadInt() int`      | Читает строку из ввода и возвращает записанное в ней целое число со знаком   |
| `abs(x int) int`         | Возвращает модуль числа                                                      |
| `min(a int, ...int) int` | Принимает 1 или более аргументов и возвращает наименьшее из переданных чисел |
| `max(a int, ...int) int` | Принимает 1 или более аргументов и возвращает наибольшее из переданных чисел |

Строка, прочитанная `fmt.ReadInt`, может содержать пробельные символы в начале и в конце.

## Выполнение программы

1. Интерпретатор принимает путь к файлу с исходным кодом первым аргументом командной строки.
2. Ввод программы читается из стандартного потока ввода, вывод записывается в стандартный поток вывода.
3. При лексической, синтаксической ошибке или ошибке выполнения интерпретатор прекращает работу, выводит сообщение об ошибке в стандартный поток ошибок и завершается с ненулевым кодом возврата.
4. Программа выполняется только после успешного разбора всего файла: при лексической или синтаксической ошибке инструкции не выполняются, а при ошибке выполнения вывод предшествующих инструкций сохраняется.
