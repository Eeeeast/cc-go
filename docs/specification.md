# Спецификация языка MiniGo

## Введение

MiniGo - это минималистичный язык с синтаксисом похожим на Go, предназначенный для обучения разработке интерпретаторов в рамках прохождения курса по теории формальных языков программирования.

### Особенности
1. Программа является модулем, который состоит из одного файла с исходным кодом, точка входа - функция `main`.

2. Основной стиль программирования процедурный(прогрмма представляет из себя набор функций)

3. Базовые типы представленные в интерпретаторе:
    - `int` - 64-битное целое число со знаком;
    - `string` - строка;
    - `bool` - булево значение.

5. В рамках интепретатора доступны логические, арифметические операторы и операторы сравнения.

6. Доступны блоки `if`/`else`, цикл `loop` с выходом благодаря инструкцией `break`.

7. Массивы: представлют из себя срезы, которые создаются встроенной функцией `make`, длину находит встроенная функция `len`.

8. Ввод и вывод выполняются встроенными функциями пакета fmt.

9. В языке нет методов, интерфейсов, замыканий, отображений, констант, глобальных переменных, множественных возвращаемых значений и параллельного программирования.

## Лексика


### Пробельные символы

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x9      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

### Комментарии

1. Строчный комментарий начинается с `//` и идет до конца строки.
2. Блок комментария(многострочный) начинается с `/*` и заканчивается `*/`.
3. Комментарии игнорируются при разборе.

### Идентификаторы

1. Идентификатор - последовательность букв, цифр и допустимых символов, которая начинается с буквы.
2. Идентификатор не может совпадать с ключевым или зарезервированным словом.
3. Идентификатор с заглавной буквы является публичным, со строчной приватным.

### Разделители инструкций

Инструкции и объявления разделяются `;`. Лексер сам вставляет `;` в конце строки, в случае необходимости.

1. Токен `;` вставляется после последнего токена строки, если этот токен:
    - идентификатор;
    - литерал целого числа или литерал строки;
    - ключевое слово;
    - одна из лексем `)`, `]`, `}`.
2. Конец файла приравнивается к концу строки.
3. Пустые строки и строки, состоящие только из комментариев, не порождают токен `;`.

### Лексические ошибки

Лексической ошибкой является:

1. символ, с которого не может начинаться ни одна лексема, например `#`, `&` или `|` без пары;
2. литерал строки, не закрытый до конца строки или файла;
3. недопустимая экранированная последовательность в литерале строки;
4. блочный комментарий, не закрытый до конца файла;
5. литерал целого числа, нарушающий правила раздела «Литералы целых чисел»;
6. последовательность `++`, `--` или `<-`.
