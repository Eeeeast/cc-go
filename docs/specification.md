# Спецификация языка MiniGo

## Введение

MiniGo — минималистичный язык с синтаксисом, похожим на Go. Он предназначен для обучения разработке интерпретаторов в рамках курса по теории формальных языков программирования.

### Особенности

1. Программа состоит из одного файла с исходным кодом. Точка входа — функция `main`.
2. Основной стиль программирования — процедурный. Программа является набором функций.
3. Базовые типы:
   - `int` — 64-битное целое число со знаком;
   - `string` — строка;
   - `bool` — булево значение.
4. Есть ветвление `if`/`else` и цикл `for`, из которого можно выйти с помощью `break` и `continue`.
5. Массивы — срезы, создаваемые функцией `make`, длина массива определяется функцией `len`.
6. Есть структуры `struct`.
7. Переменные объявляются явно. Для объявления используются `var` или `:=`.
8. Вывод выполняется встроенной функцией `fmt.Println`.

## Лексика

### Пробельные символы

Пробельные символы разделяют лексемы.

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

### Комментарии

1. Строчный комментарий начинается с `//` и идёт до конца строки.
2. Блочный комментарий (многострочный) начинается с `/*` и заканчивается первым `*/`.
3. Комментарии игнорируются при разборе.

### Идентификаторы

1. Идентификатор — последовательность латинских букв, цифр и знака `_`, которая начинается с латинской буквы или знака `_`.
2. Регистр имеет значение: `count` и `Count` — разные идентификаторы.
3. Идентификатор не может совпадать с ключевым словом.

### Ключевые слова

```
break   continue  for     if    else
func    struct    return  true  false  type  var
```

Ключевые слова пишутся только строчными буквами. `IF` и `If` — обычные идентификаторы. `make` и `len` — также обычные идентификаторы.

### Литералы целых чисел

1. Литерал — последовательность цифр.
2. Литерал не содержит знака: отрицательное число — это оператор `-` и литерал.
3. Дробные литералы не поддерживаются.

### Литералы строк

Литерал заключён в двойные кавычки: `"строка"`. Внутри возможны любые символы, кроме `"`, `\` и переноса строки. Символы `"` и `\` записываются через `\`:

| Запись | Символ               |
| ------ | -------------------- |
| `\"`   | двойная кавычка      |
| `\\`   | обратная косая черта |
| `\n`   | перевод строки       |
| `\t`   | табуляция            |

Перенос строки внутри литерала, незакрытый литерал и любая другая последовательность после `\` — лексические ошибки.

### Операторы

| Группа         | Лексемы                     |
| -------------- | --------------------------- |
| Арифметические | `+` `-` `*` `/` `%`         |
| Сравнения      | `==` `!=` `<` `<=` `>` `>=` |
| Логические     | `&&` `\|\|` `!`             |
| Присваивание   | `=` `:=`                    |

### Разделители

`(` `)` `[` `]` `{` `}` `,` `;` `.`

### Разделители инструкций

Токен `;` разделяет инструкции. Лексер не вставляет `;` автоматически. Токен присутствует в потоке только там, где он явно написан в исходнике.

1. Каждая инструкция завершается токеном `;`.
2. В одной строке может быть несколько инструкций, разделённых `;`.
3. Пустая инструкция между двумя `;` не допускается.

### Лексические ошибки

1. Символ, с которого не может начинаться ни одна лексема.
2. Одиночные `&`, `|` и `:`.
3. Литералы, нарушающие правила написания.
4. Незакрытый блочный комментарий.
