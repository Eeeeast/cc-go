- [x] Идентификатор с подчёркиванием внутри и в начале
- [x] Идентификатор с цифрами после буквы
- [x] Граница с ключевым словом
- [x] Ключевые слова в ином регистре считаются идентификаторами
- [x] Имя типа считается идентификатором
- [x] Разбор ключевых слов действий
- [x] Разбор ключевых слов терминаторов
- [x] Разбор булевых литералов

- [x] Знак минус перед числом считается оператором

- [x] Разбор строковых литералов
- [x] Escape последовательность `\"`

- [x] Разбор операторов сравнения
- [x] Разбор логических операторов

- [x] Разбор блочного комментария

## Поток токенов

- [x] Разбор полной программы

## API лексера

- [x] `FromFile` читает существующий файл
- [x] `FromFile` возвращает ошибку на отсутствующий файл
- [x] `ReadString` возвращает исходный текст с кавычками
- [x] `ReadNumeric` возвращает цифры и останавливается на не цифре
- [x] `ReadNumeric` на не цифре возвращает пустую строку без ошибки
- [x] `MatchChar` возвращает ложь при несовпадении
- [x] `PeekChars` возвращает ложь при коротком входе
- [x] `EatCh` на конце файла возвращает ноль
