# Список тестов виртуальной машины

## Инструкции

- [x] `OpPush` кладёт значение в стек
- [x] `OpPop` снимает значение со стека
- [x] `OpPop` на пустом стеке даёт `stack underflow`
- [x] `OpAdd` складывает два операнда
- [x] `OpSub` вычитает
- [x] `OpMul` умножает
- [x] `OpDiv` делит с округлением к нулю
- [x] `OpMod` берёт остаток со знаком делимого
- [x] `OpNeg` меняет знак
- [x] `OpCallPrintln` печатает значение и кладёт `Void`
- [x] `OpCallReadInt` читает целое число
- [x] `OpCallAbs` возвращает модуль
- [x] `OpCallMin` возвращает меньшее
- [x] `OpCallMax` возвращает большее

## Ошибки выполнения

- [x] Деление на ноль
- [x] Остаток от деления на ноль
- [x] Переполнение при сложении
- [x] Переполнение при вычитании
- [x] Переполнение при умножении
- [x] Переполнение при унарном минусе (`-(-9223372036854775808)`)
- [x] Переполнение при `abs(-9223372036854775808)`
- [x] Использование `Void` в арифметике
- [x] Неизвестный опкод

## Ввод

- [x] `ReadInt` с обычным числом
- [x] `ReadInt` с отрицательным числом
- [x] `ReadInt` с пробелами вокруг
- [x] `ReadInt` на пустой строке
- [x] `ReadInt` на нечисловой строке
- [x] `ReadInt` при EOF
