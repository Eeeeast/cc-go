# Список приёмочных тестов

## Успешные программы

- [x] `celsius2fahrenheit`: ввод 100, вывод 212
- [x] `clamp`: ввод 150, вывод 100 (`max(0, min(100, x))`)
- [x] `arith`: `10 + 7 * (2 * 3 + 4) + 5 + -5` = 80
- [x] `divmod`: деление и остаток с отрицательными
- [x] `builtins`: `abs`, `min`, `max`

## Программы с ошибками

- [x] `div0`: деление на ноль
- [x] `unknown_func`: неизвестная функция
- [x] `missing_semicolon`: отсутствие `;`
