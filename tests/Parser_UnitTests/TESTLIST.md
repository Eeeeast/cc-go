# Список тестов парсера

## Правила грамматики

- [x] `program` целиком: `func main() { ... }`
- [x] `program` с пустым телом: `func main() {}`
- [x] `statement`: выражение с `;`
- [x] `additive_expression`: `1 + 2`, `1 - 2`, левая ассоциативность
- [x] `multiplicative_expression`: `*`, `/`, `%`, приоритет над `+` и `-`
- [x] `unary_expression`: один и два унарных минуса, минус перед вызовом и скобками
- [x] `primary_expression`: целочисленный литерал, скобки, вложенные скобки
- [x] `call_expression`: с префиксом `fmt.`, без префикса, с аргументом, без аргументов
- [x] `argument_list`: один аргумент, несколько аргументов через `,`

## Ошибки синтаксиса

- [x] Пустой вход
- [x] Отсутствует `func`
- [x] Отсутствует `main`
- [x] Отсутствует `(`, `)`, `{`, `}`
- [x] Лишние токены после `}`
- [x] Отсутствует `;` после выражения
- [x] Переполнение целочисленного литерала
- [x] Незакрытая скобка в выражении
- [x] Пустые скобки `()`
- [x] Неизвестная функция
- [x] Неверная арность: `abs()`, `abs(1, 2)`, `min(1)`, `min(1, 2, 3)`, `fmt.Println()`, `fmt.ReadInt(1)`
- [x] Идентификатор без вызова: `x;`
- [x] Отсутствует `(` в вызове
- [x] Отсутствует `)` в вызове
